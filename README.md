# Blütenzupfer

Eine kleine Web-App, in der man die Blütenblätter einzelner Blumen pflücken kann –
ganz klassisch: *Er liebt mich … er liebt mich nicht.*

## Starten

Einfach `index.html` im Browser öffnen – keine Installation, kein Build.

## So funktioniert's

- **Antippen** eines Blütenblatts zupft es ab, es segelt auf die Wiese.
- **Ziehen** mit Maus oder Finger reißt das Blatt ab – man kann es werfen.
- Tastatur: Blume fokussieren und **Enter** / **Leertaste** drücken.
- Unten wählt man die Blume: Gänseblümchen, Sonnenblume, Mohn, Kirschblüte, Kornblume, Rose.
  Jede neue Blume hat eine zufällige Anzahl Blätter.
- Oben wählt man das Orakel: „Er/Sie liebt mich … nicht“, der klassische Reim
  „von Herzen, mit Schmerzen, ein wenig, gar nicht“, „Ja / Nein“ oder „Ich trau mich … nicht“.
- Das letzte Blatt entscheidet.
